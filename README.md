# Hagen Laboratorio de IA | Skills

Skills para OpenCode, listas para copiar y usar. Sin registro y sin costo.

## Skills disponibles

| Skill | Para qué sirve |
|---|---|
| `estacionamiento-ideas-y-foco` | Coach de enfoque: guarda las ideas que saltan en medio del trabajo y te devuelve a la tarea activa. |
| `memoria-central-setup` | Manual para armar una memoria central por proyecto en OpenCode y replicarla en otra máquina. |

Cada skill tiene su `SKILL.md` en español y una versión `SKILL.en.md` en inglés.

## Cómo instalar

1. Descarga la carpeta del skill que quieras.
2. Cópiala en `~/.config/opencode/skills/`.
3. Listo. OpenCode la activa solo cuando encaja con lo que estás haciendo.
